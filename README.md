# 🤖 AI-Powered Employee Performance Analytics Pipeline

An end-to-end data engineering project analyzing 100,000 employee 
records with AI-generated insights.

## 🛠️ Tech Stack
- **Snowflake** — Cloud data warehouse (100K rows)
- **dbt** — Data transformation models (staging → marts)
- **Python** — ELT pipeline and data loading
- **Groq LLaMA** — AI-generated workforce insights
- **Streamlit** — Interactive dashboard

## 📊 What It Does
1. Loads 100K employee records into Snowflake
2. Transforms raw data using dbt models
3. AI analyzes KPIs and writes plain-English insights
4. Dashboard shows department performance with filters

## 🚀 Key Features
- Department performance comparison (color-coded)
- AI-generated executive summary and recommendations
- Employee explorer with filters
- 10% resignation rate analysis across 9 departments
